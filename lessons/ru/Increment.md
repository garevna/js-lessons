## ![ico-25 icon] Инкремент⟪Increment⟫

Инкремент - это увеличение значения числовой переменной на единицу.

Постфиксная форма: **~y++~**

Префиксная форма: **~++y~**

Постфиксная форма означает, что переменная будет увеличена после операции, в которой она принимает участие

![ico-25 cap]

~~~javascript
var x = 0, y = 2
var z = y + x++
~~~

^^После операции:^^

~~~javascript
var z = y + x++
~~~

^^значение переменной **z** будет ~2 + 0 = 2~^^,
^^а значение переменной **x** станет равным ~1~^^.

^^А вот после такой операции:^^

~~~javascript
var x = 0, y = 2
var z = y + ++x
~~~

^^сначала значение переменной **x** станет ~0 + 1 = 1~,^^
^^а затем будет вычислено значение переменной **z**: ~2 + 1 = 3~^^.

________________________________________________________

## ![ico-25 icon] Декремент⟪Decrement⟫

Все то же самое, только значение не увеличивается на 1, а уменьшается ![ico-25 smile]

~~~javascript
var x = 0, y = 2
var z = --y + ++x
~~~

^^сначала значение переменной **y** станет ~2 - 1 = 1~,^^
^^значение переменной **x** станет ~0 + 1 = 1~^^,
^^а затем будет вычислено значение переменной **z**: ~1 + 1 = 2~^^.

## ![ico-25 hw] Тесты⟪Tests⟫

♣♣♣♣
? Чему будут равны **z** и **x** после **var x = 0, y = 2; var z = y + x++**?

+ **z = 2**, **x = 1**
= Верно! В выражение **x** вошёл прежним значением — нулём, поэтому **z** равно двум. Увеличение произошло, но после: **x** стал единицей.

- **z = 3**, **x = 1**
= Неверно. Тройка получилась бы у префиксной формы — **y + ++x**: там **x** увеличивается до того, как войдёт в выражение.

- **z = 2**, **x = 0**
= Неверно. **z** посчитано правильно, но про **x** забыли: постфиксная форма тоже увеличивает переменную, просто позже.

- **z = 3**, **x = 0**
= Неверно. Это обе ошибки сразу: значение в выражение вошло бы новым, а переменная осталась бы старой — так не бывает ни при одной из форм.

? Чем отличаются постфиксная **x++** и префиксная **++x** формы как выражения?

- Ничем: обе увеличивают **x** на единицу.
= Неверно. Переменную они и правда увеличивают одинаково, но значение самого выражения у них разное — именно поэтому форма и имеет значение.

+ **x++** возвращает прежнее значение, **++x** — уже увеличенное.
= Верно! Переменная в обоих случаях станет на единицу больше, а в выражение войдёт разное: прежнее значение у постфиксной формы и новое у префиксной. Там, где результат никуда не идёт — **for (let i = 0; i < 10; i++)** — разницы нет. То же и у декремента.

- **++x** работает только с числами, **x++** — с любыми значениями.
= Неверно. Обе формы приводят операнд к числу одинаково: из строки **'5'** выйдет **6**, а из строки **'пять'** — **NaN**.

- **x++** увеличивает на единицу, **++x** — на две.
= Неверно. Два плюса — это знак операции, а не её величина: обе формы прибавляют единицу.

? Чему будет равно **x** после **var x = 5; x = x++**?

- **6**
= Неверно — и это самая частая ошибка с инкрементом. Увеличение происходит, но его результат тут же затирается присваиванием.

+ **5**
= Верно! Справа стоит постфиксная форма, её значение — прежняя пятёрка. **x** успевает стать шестёркой, но тут же получает обратно пятёрку из присваивания. Чтобы увеличить, достаточно написать **x++** без присваивания.

- **NaN**
= Неверно. **NaN** появился бы, если бы в **x** лежало что-то, не приводимое к числу; здесь это число.

- Синтаксическая ошибка
= Неверно. Запись совершенно законная — тем она и опасна: ошибка не в синтаксисе, а в том, что результат пропадает молча.

? Чему будут равны **z**, **y** и **x** после **var x = 0, y = 2; var z = --y + ++x**?

+ **z = 2**, **y = 1**, **x = 1**
= Верно! Обе формы префиксные, поэтому обе переменные меняются до сложения: **y** становится единицей, **x** тоже, и в сумме выходит два.

- **z = 3**, **y = 1**, **x = 1**
= Неверно. Тройка вышла бы, если бы **y** вошёл в сумму прежней двойкой, то есть у постфиксной формы **y--**. Здесь форма префиксная.

- **z = 2**, **y = 2**, **x = 1**
= Неверно. Сумма посчитана правильно, но **y** не остался двойкой: декремент его уменьшил — иначе и слагаемого «один» бы не было.

- **z = 1**, **y = 1**, **x = 0**
= Неверно. **x** увеличивается тоже — и до сложения: **++x** делает его единицей, и она идёт в сумму.

? Чему будут равны **m** и **n** после **var n = 3; var m = n-- - --n**?

+ **m = 2**, **n = 1**
= Верно! Слева направо: **n--** отдаёт в выражение тройку и делает **n** двойкой; затем **--n** делает **n** единицей и отдаёт единицу. Три минус один — два, а **n** остаётся единицей.

- **m = 0**, **n = 1**
= Неверно. Ноль вышел бы, если бы оба слагаемых взяли одно и то же значение **n**. Но **n** меняется прямо посреди выражения: уменьшаемое — тройка, вычитаемое — единица.

- **m = 1**, **n = 1**
= Неверно. Единица вышла бы из **2 - 1** — то есть если бы **n--** отдал в выражение уже уменьшенное значение. Постфиксная форма отдаёт прежнее, тройку.

- **m = 2**, **n = 2**
= Неверно. Разность посчитана правильно, но **n** уменьшался дважды, а не один раз: с тройки до единицы.

? Что окажется в **s** и какого типа после **var s = '5'; s++**?

- Строка **'6'**
= Неверно. Тип не сохраняется: инкремент — арифметическая операция, её результат всегда число.

- Строка **'51'**
= Неверно. Склеивание даёт плюс между двумя значениями — **'5' + 1**. Инкремент к строке не приклеивает ничего, он приводит её к числу.

+ Число **6**
= Верно! Инкремент сначала приводит операнд к числу, и **typeof s** после этого — **'number'**. Если привести не выйдет — **var s = 'пять'; s++** — получится **NaN**, тоже число. Декремент ведёт себя так же.

- **NaN**
= Неверно. **NaN** получился бы из строки, которую нельзя прочитать как число. Строка **'5'** читается прекрасно.
