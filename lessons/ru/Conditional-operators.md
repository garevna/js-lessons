# ![ico-30 icon] Условные операторы⟪Conditional_operators⟫

Само название "условные операторы" уже говорит нам о том, что они отличаются от всех остальных операторов тем, что в них будет какое-то **условие**.

•••• none
Условия часто встречаются в нашей повседневной жизни.
"Ты пойдешь в кино при условии, что выполнишь домашнее задание".
Очевидно, что эта фраза предполагает два варианта: либо я пойду в кино, либо нет.
И выбор одного из двух этих вариантов зависит от выполнения или невыполнения условия: выполнение домашнего задания.
••••

Очевидно, мы столкнулись с [►►►**ветвлением**►►►](page/Block-diagram#Branching).

Обычная [►►►последовательность►►►](page/Block-diagram#Sequence) выполнения кода соответствует порядку следования команд:

~~~js
var x = 5            // будет выполнена первой
var y = 11           // будет выполнена второй
var z = x * y + 5    // будет выполнена третьей
~~~

Условный оператор обеспечивает возможность ветвления скрипта в зависимости от выполнения определенного условия.

## ![ico-25 icon] Оператор if⟪The_if_statement⟫

~~~js
Если (домашнее задание выполнено) {
  идем в кино
} в противном случае {
  остаемся дома и делаем домашку
}
~~~

Какое бы выражение вы не поместили в круглые скобки, движок вычислит его значение и приведет его к типу ~boolean~, т.е. в круглых скобках может быть любое синтаксически верное выражение, но в результате вычисления значения этого выражения движок получит либо **~true~**, либо **~false~**.

~~~js
Если (!!выражение) {
  делаем так
} в противном случае {
  делаем что-то другое
}
~~~

Осталось заменить **~Если~** на **~if~** и **~в противном случае~** на **~else~**:

Синтаксис:

~~~js
if (!!выражение) {  
  скрипт 1
} else {
  скрипт 2
}
~~~

В этой записи появляется две ветки кода: <span class="first-expression">скрипт 1</span> <span class="second-expression">скрипт 2</span>

Какая ветка кода будет выполнена, зависит от логического значения выражения в круглых скобках оператора **~if~**.

| значение выражения в круглых скобках оператора **~if~**<br />после приведения к логическому типу **~boolean~**       | выполняться будет   |
| **~true~**    | <span class="first-expression">скрипт 1</span> |
| **~false~**   | <span class="second-expression">скрипт 2</span> |

^^^[Примечание:]

^^Если в теле условного оператора **~if~** всего одна операция, фигурные скобки можно опустить:^^

~~~js
if (i % 2 === 0) console.log(i)

if (i % 2 !== 0) continue
~~~

^^**%** - операция взятия остатка от деления^^

^^^

_________________________________________________________________

◘◘![ico-25 cap] Пример 1◘◘

~~~js
if (typeof x === 'number') {
  var z = x * 5
  var y = x / 10 - 3
}
else {
  var z = 0
  var y = 0
}
~~~

^^Здесь код разветвляется: первая "ветка" кода будет выполнена тогда, когда переменная **~ x ~** будет числом.^^

^^В этом случае переменной **~ z ~** будет присвоено значение ~x * 5~,<br />а переменной **~ y ~** значение выражения ~x / 10 - 3~^^

^^В противном случае (когда **~ x ~** не является числом) переменные **~ z ~** и **~ y ~** получат значение **0**.^^

## ![ico-25 icon] Тернарный оператор⟪The_ternary_operator⟫

Синтаксис:

<span class="condition-expression">Условие</span><span class="ternary-sign">?</span><span class="first-expression">выражение 1</span><span class="ternary-sign">:</span><span class="second-expression">выражение 2</span>

Все правильно

Ошибка

![ico-20 warn] Символы **~?~** и **~:~** являются неотъемлемой частью конструкции тернарного оператора.

Вычисляется значение ~условия~ и приводится к логическому типу.

| <span class="condition-expression">Условие</span> |  тернарный оператор вычисляет и возвращает значение                                                       |
| **~true~**                                                     | <span class="first-expression">выражение 1</span>  |
| **~false~**                                                    | <span class="second-expression">выражение 2</span> |



_____________________________________________________________

◘◘![ico-25 cap] **1**◘◘

~~~js
var meet = source === 'fruit' ? 'apple' : 'mashroom'
~~~

Здесь первый операнд тернарного оператора (условие) является логическим выражением: ~sourse === 'fruit'~.

Переменная **~source~** либо равна ~'fruit'~, либо нет. Если переменная **~source~** является строкой и имеет значение ~'fruit'~, то это условие примет значение ~true~, и переменной **~meet~** будет присвоено значение 'apple'

В противном случае переменной **~meet~** будет присвоено значение 'mashroom'.

~~~demo
> var source = 'fruit'
< undefined
> var meet = source === 'fruit' ? 'apple' : 'mashroom'
< undefined
> meet
< 'apple'
> source = null
< null
> meet = source === 'fruit' ? 'apple' : 'mashroom'
< 'mashroom'
~~~

______________________________________________________________

◘◘![ico-25 cap] **2**◘◘

~~~js
var result = expresion ? 'Все правильно' : 'Ошибка'
~~~

Если Boolean(expresion) имеет значение ~true~, то значением переменной **~result~** будет строка **~"Все правильно"~**.

В противном случае значением переменной **~result~** будет строка **~"Ошибка"~**.

Например, в следующем случае **~result~** получит значение **~"Все правильно"~**:

~~~js
var expresion = 'Google'
var result = expresion ? 'Все правильно' : 'Ошибка'
~~~

а в этом случае **~result~** получит значение  **~"Ошибка"~**:

~~~js
var expresion = null
var result = expresion ? 'Все правильно' : 'Ошибка'
~~~

~~~demo
> var x = 8
< undefined
> var expresion = x > 5
< undefined
> var result = expresion ? 'Все правильно' : 'Ошибка'
< undefined
> meet
< 'Все правильно'
> expresion = x < 5
< false
> result = expresion ? 'Все правильно' : 'Ошибка'
< 'Ошибка'
~~~
