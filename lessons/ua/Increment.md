## ![ico-25 icon] Інкремент⟪Increment⟫

Інкремент — це збільшення значення числової змінної на одиницю.

Постфіксна форма: **~y++~**

Префіксна форма: **~++y~**

Постфіксна форма означає, що змінна буде збільшена після операції, в якій вона бере участь.

![ico-25 cap]

~~~javascript
var x = 0, y = 2
var z = y + x++
~~~

^^Після операції:^^

~~~javascript
var z = y + x++
~~~

^^значення змінної **z** буде ~2 + 0 = 2~^^,
^^а значення змінної **x** стане рівним ~1~^^.

^^А ось після такої операції:^^

~~~javascript
var x = 0, y = 2
var z = y + ++x
~~~

^^спочатку значення змінної **x** стане ~0 + 1 = 1~,^^
^^а потім буде обчислено значення змінної **z**: ~2 + 1 = 3~^^.

________________________________________________________

## ![ico-25 icon] Декремент⟪Decrement⟫

Все те саме, тільки значення не збільшується на 1, а зменшується ![ico-25 smile]

~~~javascript
var x = 0, y = 2
var z = --y + ++x
~~~

^^спочатку значення змінної **y** стане ~2 - 1 = 1~,^^
^^значення змінної **x** стане ~0 + 1 = 1~^^,
^^а потім буде обчислено значення змінної **z**: ~1 + 1 = 2~^^.

## ![ico-25 hw] Тести⟪Tests⟫

♣♣♣♣
? Чому дорівнюватимуть **z** і **x** після **var x = 0, y = 2; var z = y + x++**?

+ **z = 2**, **x = 1**
= Правильно! У вираз **x** увійшов попереднім значенням — нулем, тому **z** дорівнює двом. Збільшення відбулося, але після: **x** став одиницею.

- **z = 3**, **x = 1**
= Неправильно. Трійка вийшла б у префіксної форми — **y + ++x**: там **x** збільшується до того, як увійде у вираз.

- **z = 2**, **x = 0**
= Неправильно. **z** пораховано правильно, але про **x** забули: постфіксна форма теж збільшує змінну, просто пізніше.

- **z = 3**, **x = 0**
= Неправильно. Це обидві помилки одразу: значення у вираз увійшло б новим, а змінна лишилася б старою — так не буває за жодної з форм.

? Чим відрізняються постфіксна **x++** і префіксна **++x** форми як вирази?

- Нічим: обидві збільшують **x** на одиницю.
= Неправильно. Змінну вони й справді збільшують однаково, але значення самого виразу в них різне — саме тому форма й має значення.

+ **x++** повертає попереднє значення, **++x** — уже збільшене.
= Правильно! Змінна в обох випадках стане на одиницю більшою, а у вираз увійде різне: попереднє значення в постфіксної форми і нове в префіксної. Там, де результат нікуди не йде — **for (let i = 0; i < 10; i++)** — різниці немає. Те саме й у декремента.

- **++x** працює лише з числами, **x++** — з будь-якими значеннями.
= Неправильно. Обидві форми приводять операнд до числа однаково: з рядка **'5'** вийде **6**, а з рядка **'п’ять'** — **NaN**.

- **x++** збільшує на одиницю, **++x** — на дві.
= Неправильно. Два плюси — це знак операції, а не її величина: обидві форми додають одиницю.

? Чому дорівнюватиме **x** після **var x = 5; x = x++**?

- **6**
= Неправильно — і це найчастіша помилка з інкрементом. Збільшення відбувається, але його результат одразу ж затирається присвоєнням.

+ **5**
= Правильно! Праворуч стоїть постфіксна форма, її значення — попередня п’ятірка. **x** встигає стати шісткою, але одразу ж отримує назад п’ятірку з присвоєння. Щоб збільшити, достатньо написати **x++** без присвоєння.

- **NaN**
= Неправильно. **NaN** з’явився б, якби в **x** лежало щось, що не приводиться до числа; тут це число.

- Синтаксична помилка
= Неправильно. Запис цілком законний — тим він і небезпечний: помилка не в синтаксисі, а в тому, що результат зникає мовчки.

? Чому дорівнюватимуть **z**, **y** і **x** після **var x = 0, y = 2; var z = --y + ++x**?

+ **z = 2**, **y = 1**, **x = 1**
= Правильно! Обидві форми префіксні, тому обидві змінні змінюються до додавання: **y** стає одиницею, **x** теж, і в сумі виходить два.

- **z = 3**, **y = 1**, **x = 1**
= Неправильно. Трійка вийшла б, якби **y** увійшов у суму попередньою двійкою, тобто в постфіксної форми **y--**. Тут форма префіксна.

- **z = 2**, **y = 2**, **x = 1**
= Неправильно. Сума порахована правильно, але **y** не лишився двійкою: декремент його зменшив — інакше й доданка «один» не було б.

- **z = 1**, **y = 1**, **x = 0**
= Неправильно. **x** збільшується теж — і до додавання: **++x** робить його одиницею, і вона йде в суму.

? Чому дорівнюватимуть **m** і **n** після **var n = 3; var m = n-- - --n**?

+ **m = 2**, **n = 1**
= Правильно! Зліва направо: **n--** віддає у вираз трійку й робить **n** двійкою; потім **--n** робить **n** одиницею і віддає одиницю. Три мінус один — два, а **n** лишається одиницею.

- **m = 0**, **n = 1**
= Неправильно. Нуль вийшов би, якби обидва доданки взяли одне й те саме значення **n**. Але **n** змінюється просто посеред виразу: зменшуване — трійка, від’ємник — одиниця.

- **m = 1**, **n = 1**
= Неправильно. Одиниця вийшла б із **2 - 1** — тобто якби **n--** віддав у вираз уже зменшене значення. Постфіксна форма віддає попереднє, трійку.

- **m = 2**, **n = 2**
= Неправильно. Різниця порахована правильно, але **n** зменшувався двічі, а не один раз: із трійки до одиниці.

? Що опиниться в **s** і якого типу після **var s = '5'; s++**?

- Рядок **'6'**
= Неправильно. Тип не зберігається: інкремент — арифметична операція, її результат завжди число.

- Рядок **'51'**
= Неправильно. Склеювання дає плюс між двома значеннями — **'5' + 1**. Інкремент до рядка не приклеює нічого, він приводить її до числа.

+ Число **6**
= Правильно! Інкремент спершу приводить операнд до числа, і **typeof s** після цього — **'number'**. Якщо привести не вийде — **var s = 'п’ять'; s++** — вийде **NaN**, теж число. Декремент поводиться так само.

- **NaN**
= Неправильно. **NaN** вийшов би з рядка, який не можна прочитати як число. Рядок **'5'** читається чудово.
