### push⟪push⟫

Цей метод додає новий елемент до кінця масиву.
Аргументом, який отримує метод під час виклику, є додаваний елемент.
Метод повертає нову довжину масиву.

^^^[push()]

![ico-25 cap] ** 1**

~~~js
var array = ['Nail', 'Bicycle', 'Processor', 'Disk']
var length = array.push('Program')
~~~

^^Після виконання цього коду в масиві **array** будуть елементи:^^

••['Nail', 'Bicycle', 'Processor', 'Disk', 'Program']••


^^а значення змінної **~length~** дорівнюватиме 5^^

^^^

____________________________________________________________________

### pop⟪pop⟫

^^^[pop()]

Цей метод видаляє останній елемент масиву та повертає видалений елемент

У методу немає параметрів (аргументів)

![ico-25 cap] ** 1**

~~~js
var array = ['Nail', 'Bicycle', 'Processor', 'Disk', 'Program']
var elem = array.pop()
~~~

^^Після виконання цього коду в масиві **array** залишаться:^^

••['Nail', 'Bicycle', 'Processor', 'Disk']••

^^а значення змінної  ~elem~  буде  “Program”^^
^^^

_________________________________________________________________________

### shift⟪shift⟫

Цей метод видаляє перший елемент із масиву.
Повернуте значення — видалений елемент.

^^^[shift()]

![ico-25 cap] ** 1**

^^Наприклад, внаслідок виконання такого коду:^^

~~~js
var arrayOfThings = ['Nail', 'Bicycle', 'Processor', 'Disk', 'Program']
console.log(arrayOfThings.shift())
~~~

^^у консолі буде:  _Nail_^^

^^а масив **arrayOfThings** міститиме такі значення:^^

••['Bicycle', 'Processor', 'Disk', 'Program']••

^^^

______________________________________________________

### unshift⟪unshift⟫

Цей метод додає новий елемент на початок масиву.
Повернуте значення — нова довжина масиву (число).

^^^[unshift()]

![ico-25 cap] ** 1**

~~~js
var drinks = ['coffee', 'tea', 'juice', 'water', 'milk']
var len = drinks.unshift('beer')
~~~

^^В результаті масив **drinks** міститиме такі елементи:^^

••['beer', 'coffee', 'tea', 'juice', 'water', 'milk']••

^^а змінна ~len~ прийме значення 6^^
^^^

### splice⟪splice⟫

Перший аргумент (число) визначає позицію (індекс), куди будуть вставлені нові елементи.
Другий аргумент (число) визначає, скільки елементів (починаючи з позиції вставки) має бути видалено з масиву.
Третій (четвертий, п’ятий ...) аргументи — це елементи, які потрібно вставити в масив.
Метод повертає видалені елементи масиву (масив).

^^^[splice()]

За допомогою методу ~splice()~ можна замінити елементи в масиві:

![ico-25 cap] ** 1**

~~~js
var myArray = [1, 2, 3, 4, 5]
console.log(myArray.splice(2, 1, '*'))
~~~

^^У результаті масив **myArray** буде:^^

••[1, 2, '*', 4, 5]••

^^а в консоль буде виведено: ~[3]~^^
^^(масив елементів, які були замінені на “*”)^^

_____________________________________

![ico-25 cap] ** 2**

~~~js
var myArray = [1, 2, 3, 4, 5]
console.log(myArray.splice(2, 2, '*', '#', '$', '%'))
~~~

^^У результаті масив **myArray** буде таким:^^


••[1, 2, '*', '#', '$', '%', 5]••


^^а в консоль буде виведено: ~[3, 4]~^^
^^(елементи, які були замінені елементами “*”, “#”, “$”, “%”)^^

______________________________________

![ico-25 cap] ** 3**

~~~js
var myArray = [1, 2, 3, 4, 5]
console.log(myArray.splice(2, 2, [7, 8, 9]))
~~~

^^У результаті масив **myArray** складатиметься з чотирьох елементів:^^

••[1, 2, Array(3), 5]••


^^а в консоль буде виведено: ~[3, 4]~^^

^^(елементи, які були замінені масивом [7, 8, 9])^^

__________________________________________________

![ico-25 cap] ** 4**

~~~js
var myArray = [1, 2, 3, 4, 5]
console.log(myArray.splice(2, 0, 'Новый элемент'))
~~~

^^У результаті масив **myArray** складатиметься з чотирьох елементів:^^

••[1, 2, 'Новый элемент', 3, 4, 5]••

^^а в консоль буде виведено порожній масив: ~[]~^^

^^(жодного елемента не було видалено з масиву, оскільки другий аргумент методу дорівнює нулю)^^

^^^

### slice⟪slice⟫

Метод створює новий масив, що містить фрагмент вихідного масиву.
При цьому вихідний масив не змінюється.
Повернуте значення — новий масив, що є фрагментом вихідного масиву.
Перший аргумент (число) — індекс елемента вихідного масиву, з якого починається фрагмент.
Другий аргумент (число) — індекс елемента вихідного масиву, до якого продовжується фрагмент.
Якщо пропустити другий аргумент, то фрагмент буде взятий до кінця вихідного масиву.

^^^[slice()]

![ico-25 cap] ** 1**

~~~js
var array = ['one', 'two', 'three', 'four', 'five']
var result = array.slice(1, 2) // ['two']
~~~

![ico-25 cap] ** 2**

~~~js
var array = ['one', 'two', 'three', 'four', 'five']
var result = array.slice(1, -2) // ['two', 'three']
~~~

![ico-25 cap] ** 3**

~~~js
var array = ['one', 'two', 'three', 'four', 'five']
var result = array.slice(-2) // ['four', 'five']
~~~

![ico-25 cap] ** 4**

~~~js
var array = ['one', 'two', 'three', 'four', 'five']
var result = array.slice(-4, -2) // ['two', 'three']
~~~

![ico-25 cap] ** 5**

~~~js
var array = ['one', 'two', 'three', 'four', 'five']
var result = array.slice(-8, 25) // ['one', 'two', 'three', 'four', 'five']
~~~

![ico-25 cap] ** 6**

~~~js
var array = ['one', 'two', 'three', 'four', 'five']
var result = array.slice(4, 3) // []
~~~

### concat⟪concat⟫

Метод об’єднує два або більше масивів у один масив.
Повернуте значення — новий масив.
Вихідні масиви не зміняться.

^^^[concat()]

![ico-25 cap] ** 1**

~~~js
var first = ['one', 'two', 'three']
var second = ['four', 'five']
var result = first.concat(second)
~~~

^^**result**:^^
••['one', 'two', 'three', 'four', 'five']••

![ico-25 cap] ** 1**

~~~js
var numbers = [1, 2, 3, 4]
var additional = [7, 8, 9]
var result = [11, 0, 5]

result = result.concat(numbers, additional)
~~~

^^**result**:^^
••► (10) [11, 0, 5, 1, 2, 3, 4, 7, 8, 9]••

^^^

### join⟪join⟫

Об’єднує всі елементи масиву в рядок ('string').
Аргумент — символ-роздільник.

^^^[join()]

![ico-25 cap] ** 1**

~~~js
var drinks = ['coffee', 'tea', 'juice', 'water', 'milk']
var menu = drinks.join(' | ')
~~~

^^**menu**:^^

••'coffee | tea | juice | water | milk'••

^^^

### includes⟪includes⟫

**ES 2016**

Метод **~includes()~** повертає ~true~, коли значення, передане аргументом, міститься в масиві, або ~false~ в іншому випадку.

^^^[includes()]

![ico-25 cap] ** 1**

~~~js
var users = ['Ivan', 'George', 'Stephan']

users.includes('Stephan')  // true
users.includes('Mary')     // false
~~~

_______________________________________________________________

![ico-25 cap] ** 2**

![ico-20 warn] Якщо елементами масиву є об’єкти, то метод не працюватиме, оскільки масиви й об’єкти — це типи даних, що посилаються.

~~~js
var users = [
  {
    name: 'Ivan',
    email: 'ivan78@gmail.com'
  },
  {
    name: 'Georg',
    email: 'georg.klep@gmail.com'
  },
  {
    name: 'Stephan',
    email: 'stephan.borg@gmail.com'
  }
]

users.includes({
  name: 'Stephan',
  email: 'stephan.borg@gmail.com'
})

//  false
~~~

______________________________________________________________

![ico-25 cap] ** 3**

~~~js
var points = [[100, 20], [200, 150], [120, 50]]

points.includes([100, 20])   // false
~~~
