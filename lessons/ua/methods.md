# ![ico-30 study] Методи

**Метод** — це властивість-функція

У наведеному нижче прикладі об’єкт **obj** має дві властивості: **name** та **showMessage**

~~~js
var obj = {
  name: 'Иван',
  showMessage: function (message) {
    console.log(message ? message : 'Привет!')
  }
}
~~~

~~~js
typeof obj.name         // "string"
typeof obj.showMessage  // "function"
~~~

Звернення до будь-якої властивості: ~имя объекта~ + ~.~ + ~имя свойства~

Від методів відрізняється лише тим, що для виклику методу після його імені потрібні круглі дужки, і якщо метод має формальні параметри — то в круглих дужках потрібно перелічити аргументи (вхідні дані)

~~~js
obj.showMessage('Я иду в магазин')
~~~

^^У результаті такого виклику в консолі буде виведено  «Я йду в магазин»^^

Таким чином, виклик методу відрізняється від виклику звичайної функції лише тим, що перед іменем методу має бути ім'я «господаря», відокремлене крапкою від імені методу

У всіх функцій (і всіх змінних) у _JS_ є «власник»

тому всі функції в _JS_ — це методи

а всі змінні — властивості

у звичайних функцій (і змінних) власником є глобальний об’єкт ( ~window~ )

усе, що не перебуває у «приватній власності», належить йому

Якщо під час звернення до властивості або виклику методу «власник» не вказано, значить цей власник — глобальний об’єкт

~~~js
var year = 2019
window.year       //  вернет 2019
~~~

### ![ico-20 file] Метод charCodeAt()

Метод ~charCodeAt()~ працює лише з рядками

Тобто будь-який рядок є «власником» методу ~charCodeAt()~

Цей метод повертає числовий код символу у заданій позиції в рядку

Номер позиції символу в рядку передається методу як параметр

◘◘![ico-25 cap] ** 1**◘◘

~~~js
var userName = 'Василий Алибабаевич',
userName.charCodeAt(4)                 // 1083
~~~

^^**1083** — це десятковий код символу *«л»* — четвертого символу від початку рядка ^^
^^(нумерація символів починається з нуля)^^

### ![ico-20 file] Метод push()

Метод  ~push ()~  працює лише з масивами

Тобто будь-який масив є «господарем» методу ~push()~

Цей метод додає новий елемент у кінець масиву

Новий елемент передається методу як параметр

◘◘![ico-25 cap] ** 2**◘◘

~~~js
var users = ['John', 'Helen', 'Mary']
users.push('Henry')
~~~

У кінець масиву **users** буде додано елемент  *«Henry»*

У результаті масив **users** матиме вигляд:  ~["Jon", "Helen", "Mary", "Henry"]~

![ico-20 warn] Метод ~push ()~ повертає нову довжину масиву

Тобто після виконання операції:

~~~js
z = users.push('Henry')
~~~

значення змінної ** z ** дорівнюватиме 4
