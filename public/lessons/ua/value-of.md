# ![ico-30 study] valueOf⟪valueOf⟫

Метод  **_~valueOf()~_**  успадковується всіма об’єктами від **~Object~**

Цей метод викликається автоматично, коли потрібно повернути примітивне значення об’єкта

Наприклад, якщо об’єкт порівнюється з числом

~~~js
var obj = {
  num: 5,
  val: 10,
  x: 11,
  valueOf: function () {
    return this.num + this.val - this.x
  }
}
~~~

Якщо тепер ми виконаємо порівняння:

~~~js
obj == 4
~~~

то отримаємо  _~true~_

Під час порівняння обчислюватиметься примітивне значення об’єкта, тобто викликатиметься метод **~valueOf()~**

Якщо примітивне значення об’єкта обчислити неможливо, то буде повернено сам об’єкт

**~valueOf ()~** — **_успадкований_** метод будь-якого об’єкта

Але це не означає, що ми не можемо його перевизначити

◘◘![ico-25 cap] ** 1 **◘◘

~~~js
var human = {
  name: 'Ivan',
  age: 25,
  valueOf: function () {
    return this.name + ': ' + this.age
  }
}

console.info(human + '!') // Ivan: 25!
~~~

___________________

Звичайно, так робити не варто, але все-таки цікаво ![ico-20 smile]

У результаті виконання наступного коду:


◘◘![ico-25 cap] ** 2 **◘◘


~~~js
Object.prototype.valueOf = function () {
  return 'Это объект, блин, а не игрушка!'
}
~~~

всі нативні об’єкти JS будуть «давати помилку» відповідним чином при спробі отримати їх примітивне значення

~~~js
console.info(Number + '')
~~~

~~~console
Это объект, блин, а не игрушка!
~~~
