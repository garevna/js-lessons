# ![ico-30 study] UTF-8

Усі символи мають числовий код

Відповідність між символом та його кодом визначається в таблиці кодування

Найширше охоплення символів різних алфавітів представлено в кодуванні UTF-8

^^(**UTF** - _Unicode Transformation Format_)^^

Під час порівняння двох рядків послідовно порівнюються числові коди символів цих рядків

^^Наприклад, десятковий код символу ** @** дорівнює 64, а десятковий код символу ** w** дорівнює 119^^

^^Логічний вираз ~"@" > "w"~ матиме значення ~false~^^

Порівняння рядків відбувається посимвольно до першого розбіжності

Логічний вираз

~~~js
'@gmail.com' < 'www.google.com'
~~~

матиме значення **~true~**, оскільки під час порівняння перших символів двох рядків буде виявлено, що код символу «@» менший за код символу «w»

далі порівняння не проводитиметься

Логічний вираз

~~~js
'@gmail.com' < '@mail.ru'
~~~

матиме значення **~true~**, оскільки коди перших символів цих рядків збігаються, а десятковий код символу «g» ( 103 ) менший за десятковий код символу «m» ( 109 )

Дізнатися код символу в певній позиції в рядку можна за допомогою методу ~charCodeAt()~

~~~js
'789'.charCodeAt(0)  // результат будет 55 - это код символа "7"
'789'.charCodeAt(1)  // результат будет 56 - это код символа "8"
'789'.charCodeAt(2)  // результат будет 57 - это код символа "9"
~~~
