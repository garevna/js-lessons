# ![ico-30 icon] Умовні оператори⟪Conditional_operators⟫

Сама назва «умовні оператори» вже вказує на те, що вони відрізняються від усіх інших операторів тим, що в них є певна **умова**.

•••• none
Умови часто зустрічаються в нашому повсякденному житті.
«Ти підеш у кіно за умови, що виконаєш домашнє завдання».
Очевидно, що ця фраза передбачає два варіанти: або я піду в кіно, або ні.
І вибір одного з цих двох варіантів залежить від виконання або невиконання умови: виконання домашнього завдання.
••••

Очевидно, ми зіткнулися з [►►►**розгалуженням**►►►](page/Block-diagram#Branching).

Звичайна [►►►послідовність►►►](page/Block-diagram#Sequence) виконання коду відповідає порядку виконання команд:

~~~js
var x = 5            // буде виконана першою
var y = 11           // буде виконана другою
var z = x * y + 5    // буде виконана третьою
~~~

Умовний оператор забезпечує можливість розгалуження скрипта залежно від виконання певної умови.

## ![ico-25 icon] Оператор if⟪The_if_statement⟫

~~~js
Якщо (домашнє завдання виконано) {
  йдемо в кіно
} в іншому випадку {
  залишаємося вдома і робимо домашнє завдання
}
~~~

Яке б вираження ви не помістили в круглі дужки, движок обчислить його значення і приведе його до типу ~boolean~, тобто в круглих дужках може бути будь-яке синтаксично правильне вираження, але в результаті обчислення значення цього вираження движок отримає або ** ~true~**, або **~false~**.

~~~js
Якщо (!!вираз) {
  тоді робимо так
} в іншому випадку {
  робимо щось інше
}
~~~

Залишилося замінити **~Якщо~** на **~if~** та **~в іншому випадку~** на **~else~**:

Синтаксис:

~~~js
if (!!вираз) {  
  скрипт 1
} else {
  скрипт 2
}
~~~

У цьому записі з’являються дві гілки коду: _~скрипт 1~_ та _~скрипт 2~_. <span class="first-expression">скрипт 1</span> <span class="second-expression">скрипт 2</span>

Яка гілка коду буде виконана, залежить від логічного значення виразу в круглих дужках оператора **~if~**.

| значення виразу в круглих дужках оператора **~if~**<br />після приведення до логічного типу **~boolean~**       | виконуватиметься   |
| **~true~**    | <span class="first-expression">скрипт 1</span> |
| **~false~**   | <span class="second-expression">скрипт 2</span> |

^^^[Примітка:]

^^Якщо в тілі умовного оператора **~if~** лише одна операція, фігурні дужки можна опустити:^^

~~~js
if (i % 2 === 0) console.log(i)

if (i % 2 !== 0) continue
~~~

^^**%** — операція обчислення залишку від ділення^^

^^^

_________________________________________________________________

◘◘![ico-25 cap] Приклад 1◘◘

~~~js
if (typeof x === 'number') {
  var z = x * 5
  var y = x / 10 - 3
}
else {
  var z = 0
  var y = 0
}
~~~

^^Тут код розгалужується: перша «гілка» коду буде виконана тоді, коли змінна **~ x ~** буде числом.^^

^^У цьому випадку змінній **~ z ~** буде присвоєно значення ~x * 5~,<br />а змінній **~ y ~** — значення виразу ~x / 10 - 3~.^^

^^В іншому випадку (коли **~ x ~** не є числом) змінні **~ z ~** та **~ y ~** отримають значення **0**.^^

## ![ico-25 icon] Тернарний оператор⟪The_ternary_operator⟫

Синтаксис:

<span class="condition-expression">Умова</span><span class="ternary-sign">?</span><span class="first-expression">вираз 1</span><span class="ternary-sign">:</span><span class="second-expression">вираз 2</span>

Все правильно

Помилка

![ico-20 warn] Символи **?** та **:** є невід’ємною частиною конструкції тернарного оператора.

Обчислюється значення ~умови~ і приводиться до логічного типу.

| <span class="condition-expression">Умова</span> |  тернарний оператор обчислює та повертає значення                                                       |
| **~true~**                                                     | <span class="first-expression">вираз 1</span>  |
| **~false~**                                                    | <span class="second-expression">вираз 2</span> |



_____________________________________________________________

◘◘![ico-25 cap] **1**◘◘

~~~js
var meet = source === 'fruit' ? 'apple' : 'mashroom'
~~~

Тут перший операнд тернарного оператора (умова) є логічним виразом: ~sourse === 'fruit'~.

Змінна **~source~** або дорівнює ~'fruit'~, або ні. Якщо змінна **~source~** є рядком і має значення ~'fruit'~, то ця умова прийме значення ~true~, і змінній **~meet~** буде присвоєно значення 'apple'.

В іншому випадку змінній **~meet~** буде присвоєно значення 'mashroom'.

~~~demo
> var source = 'fruit'
< undefined
> var meet = source === 'fruit' ? 'apple' : 'mashroom'
< undefined
> meet
< 'apple'
> source = null
< null
> meet = source === 'fruit' ? 'apple' : 'mashroom'
< 'mashroom'
~~~

______________________________________________________________

◘◘![ico-25 cap] **2**◘◘

~~~js
var result = expresion ? 'Все правильно' : 'Помилка'
~~~

Якщо ~Boolean(expresion)~ має значення ~true~, то значенням змінної **~result~** буде рядок **~"Все правильно"~**.

В іншому випадку значенням змінної **~result~** буде рядок **~"Помилка"~**.

Наприклад, у наступному випадку **~result~** отримає значення **~"Все правильно"~**:

~~~js
var expresion = 'Google'
var result = expresion ? 'Все правильно' : 'Помилка'
~~~

а в цьому випадку **~result~** отримає значення  **~"Помилка"~**:

~~~js
var expresion = null
var result = expresion ? 'Все правильно' : 'Помилка'
~~~

~~~demo
> var x = 8
< undefined
> var expresion = x > 5
< undefined
> var result = expresion ? 'Все правильно' : 'Помилка'
< undefined
> meet
< 'Все правильно'
> expresion = x < 5
< false
> result = expresion ? 'Все правильно' : 'Помилка'
< 'Помилка'
~~~

var angle = Math.PI / 2
