# Chat avatars

Eleven faces for the users in the hw-16 chat demo.

The originals were on `cdn.glitch.global` and went when Glitch wound down its
hosting in July 2025, leaving eleven broken images in a lesson that prints the
chat's data in full. These replace them, chosen to match what was there —
`begemot` was a hippo, `automat` was the Ukrainian flag, `hasbeen` was a tin
man.

They live here, in the repository, on purpose. Pointing at someone else's
server is what caused the problem in the first place.
